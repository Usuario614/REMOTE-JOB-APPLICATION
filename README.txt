REMOTE JOB KIT — LANDING PAGE
================================

FILES
- index.html — complete responsive landing page. No framework required.
- landing-design-reference.png — visual reference generated for the design direction.

HOW TO USE
1. Open index.html in a browser to preview it.
2. Replace the checkout URL:
   Search for:
   https://payhip.com/
   and replace it with the exact checkout/product URL after the Payhip product exists.
3. Replace the illustrative testimonials with real customer testimonials once you have them.
4. Upload index.html to your hosting provider.

IMPORTANT
The landing page does not process payments itself. The CTA currently points to Payhip as a placeholder.
For production, create the product in Payhip, upload the ZIP bundle, set the price, copy the checkout/product URL, and paste it into the two CTA links.
